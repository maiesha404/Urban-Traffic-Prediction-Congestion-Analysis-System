# Urban Traffic Prediction & Congestion Analysis System

A Machine Learning project that predicts traffic congestion using historical traffic data, weather conditions, and road-related features.

### Features
- Traffic congestion prediction
- Data preprocessing and EDA
- Feature engineering
- ML model comparison
- Traffic hotspot analysis
- Weather impact analysis
- Traffic Stress Index (TSI)
- Interactive Streamlit dashboard

### Tech Stack
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Plotly, Streamlit.

### Models Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor

**Best Model:** Random Forest Regressor

### Conclusion
- The Urban Traffic Prediction & Congestion Analysis System demonstrates how Machine Learning can be applied to analyse historical traffic patterns and predict congestion levels. By combining data preprocessing, feature engineering, model comparison, and an interactive Streamlit dashboard, the project provides a foundation for data-driven traffic analysis and smarter urban mobility solutions.
